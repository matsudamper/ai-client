# Paparazzi

## UI 変更時
- `@Preview` を追加/更新しスナップショットを撮影する
- 画像なしで UI 作業完了にしない

## 撮影した画像をどうするか
基準は README から参照されているかどうかで、リポジトリにコミット済みかどうかではない。

- README から参照されている画像は、撮り直した結果で更新してコミットする
- それ以外の画像は、コミットしない。PR とチャットに貼る

置き場所で基準を担保している。

- `app-android/src/test/snapshots/` は Paparazzi の出力先で、`.gitignore` 済み。ここは触らない
- `README/` は README が参照する画像の置き場で、追跡対象。撮影結果をここへコピーして更新する

出力先が丸ごと `.gitignore` 済みなので、撮影しただけでは差分は出ない。
差分が出ない状態を「更新不要」と解釈しない。README/ へのコピーは自分で行う。

## プレビュー名を変えたとき
Paparazzi の出力ファイル名はプレビュー関数名から作られるため、関数名を変えると
出力ファイル名も変わる。README が参照している画像が古い名前の出力から来ている場合は、
新しい名前の出力からコピーし直して README 側を実態に追従させる。
